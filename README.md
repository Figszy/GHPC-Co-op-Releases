# GHPC Co-op downloads

This PUBLIC repository holds versioned signed installer downloads for licensed Steam installations of Gunner, HEAT, PC! The maintained source repository Figszy/GHPC-Co-op remains PRIVATE; no source, game assets, credentials or private signing key are published here.

Install the reviewed versioned setup on both players PCs, then launch normally through Steam. Setup is a maintenance utility. Matching mod/game/protocol versions are required. Current maintenance protocol: 30.

Automatic downloads become operational only after the owner bootstraps the pinned public identity and completes a real hosted higher-version update. An inactive trust file or the presence of this repository does not establish delivery. Real two-PC gameplay validation is separate.

Release assets contain exactly the versioned setup EXE, coop-release.xml and coop-release.sig. Private source, signing tools/keys, logs and commercial game assemblies must never be uploaded. Do not replace published release assets.
